# Документация проекта Geometric Lib

## Общее описание решения
Данный проект представляет собой библиотеку на Python для работы с геометрическими фигурами. Библиотека позволяет вычислять площади и периметры круга, квадрата, прямоугольника и треугольника.

## Описание функций с примерами вызова

### Окружность (circle.py)
* **area(r)**
  * *Принимает*: радиус r, возвращает площадь круга.
  * *Заданные параметры*:
    * `r` (int/float): радиус круга
  * *Возвращаемое значение*:
    * `circle_area` (int/float): площадь круга (Пример: `area(3)` -> `28.27`)

* **perimeter(r)**
  * *Принимает*: радиус r, возвращает длину окружности.
  * *Заданные параметры*:
    * `r` (int/float): радиус круга
  * *Возвращаемое значение*:
    * `circle_perimeter` (int/float): длина окружности (Пример: `perimeter(3)` -> `18.85`)

### Квадрат (square.py)
* **area(a)**
  * *Принимает*: сторону a, возвращает площадь квадрата.
  * *Заданные параметры*:
    * `a` (int/float): сторона квадрата
  * *Возвращаемое значение*:
    * `square_area` (int/float): площадь квадрата (Пример: `area(5)` -> `25`)

* **perimeter(a)**
  * *Принимает*: сторону a, возвращает периметр квадрата.
  * *Заданные параметры*:
    * `a` (int/float): сторона квадрата
  * *Возвращаемое значение*:
    * `square_perimeter` (int/float): периметр квадрата (Пример: `perimeter(4)` -> `16`)

### Прямоугольник (rectangle.py)
* **area(a, b)**
  * *Принимает*: стороны a и b, возвращает площадь прямоугольника.
  * *Заданные параметры*:
    * `a` (int/float): первая сторона прямоугольника
    * `b` (int/float): вторая сторона прямоугольника
  * *Возвращаемое значение*:
    * `rectangle_area` (int/float): площадь прямоугольника (Пример: `area(3, 4)` -> `12`)

* **perimeter(a, b)**
  * *Принимает*: стороны a и b, возвращает периметр прямоугольника.
  * *Заданные параметры*:
    * `a` (int/float): первая сторона прямоугольника
    * `b` (int/float): вторая сторона прямоугольника
  * *Возвращаемое значение*:
    * `rectangle_perimeter` (int/float): периметр прямоугольника (Пример: `perimeter(3, 4)` -> `14`)

### Треугольник (triangle.py)
* **area(a, h)**
  * *Принимает*: основание a и высоту h, возвращает площадь треугольника.
  * *Заданные параметры*:
    * `a` (int/float): основание треугольника
    * `h` (int/float): высота треугольника
  * *Возвращаемое значение*:
    * `triangle_area` (int/float): площадь треугольника (Пример: `area(3, 4)` -> `6.0`)

* **perimeter(a, b, c)**
  * *Принимает*: стороны a, b и c, возвращает периметр треугольника.
  * *Заданные параметры*:
    * `a` (int/float): первая сторона треугольника
    * `b` (int/float): вторая сторона треугольника
    * `c` (int/float): третья сторона треугольника
  * *Возвращаемое значение*:
    * `triangle_perimeter` (int/float): периметр треугольника (Пример: `perimeter(3, 4, 5)` -> `12`)
